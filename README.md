# Lorekeeper

A local desktop app for organizing character bots, worlds, lorebooks and writing schedules.

## Setup (first time only)

1. Make sure Node.js is installed (nodejs.org → LTS version)
2. Open a terminal / command prompt in this folder
3. Run: `npm install`
4. Run: `npm start`

The app will open. Your data saves automatically to your system's app data folder and persists between sessions.

## Running after setup

Just open a terminal in this folder and run:
```
npm start
```

Or double-click `start.bat` on Windows.

## Where is my data saved?

`I:\Lorekeeper\lorekeeper-data.json`

The path is also shown in small text in the app's top bar.

## Features

- Worlds with lorebooks, collections, character lists and image gallery
- Characters with full sheet, card, example dialogue, scenarios, formatting instructions
- Calendar dashboard showing scheduled characters
- Quick search (type in the search bar)
- Import companion JSON / lorebook JSON
- Export individual characters or lorebooks back to platform format
- Full app export/import as single JSON backup
